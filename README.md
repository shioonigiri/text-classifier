# text-classifier

文章（メール・メモ）から、カテゴリ・期限・金額・必要な行動を抽出するツール。
設計の詳細は [docs/design.md](docs/design.md) を参照。

## 目的

- 文章の分類と情報抽出を自動化し、情報整理の手間を減らす
- 分類精度を測定・改善する過程まで含めて、開発の成果物にする

## 出力形式

```json
{
  "category": "選考・締切",
  "deadline": "2026-11-23",
  "amount": null,
  "action": "応募",
  "confidence": 0.8,
  "evidence": ["応募締切", "11月23日"]
}
```

カテゴリ: 選考・締切 / 就活案内 / 授業・課題 / 奨学金・手続き / セキュリティ・ログイン / 支払い・請求 / その他

## 開発段階

- v1: ルールベース（キーワード辞書＋正規表現）← 開発中
- v2: 機械学習（TF-IDF + ロジスティック回帰）
- v3: 精度評価と改善（正解率・F1・混同行列）
