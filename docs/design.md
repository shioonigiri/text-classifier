# 文章分類・情報抽出ツール 設計書

作成日: 2026-10-26
位置づけ: AI活用ロードマップ第3項「AIによる文章分類・情報抽出」の設計。収入分類AIの発展形。

## 1. 目的

メールやメモなどの文章を入力すると、カテゴリ分類と重要情報（期限・金額・行動項目）の抽出を自動で行うツールを作る。
就活での成果物として、次を説明できる状態を目指す。

- 何を解くツールか（課題設定）
- どう実装したか（ルールベース → 機械学習の段階的アプローチ）
- 精度をどう測り、どう改善したか（評価設計）

## 2. 入力と出力

### 入力
- 文章テキスト（メール件名＋本文、メモ帳ドキュメントのメモ）
- 将来拡張: Gmail・Googleドキュメントからの自動取り込み

### 出力（JSON / CSV）
| 項目 | 内容 |
|---|---|
| category | 下記のカテゴリから1つ |
| deadline | 抽出した期限（日付に正規化。なければ null） |
| amount | 抽出した金額（円。なければ null） |
| action | 必要な行動（提出・申込・参加・返信・支払い等。なければ null） |
| confidence | 分類の確からしさ（0〜1） |
| evidence | 根拠になった語句（抽出元の文字列） |

### カテゴリ（本人のGmail分類で実績のある体系を流用）
1. 選考・締切（要対応）
2. 就活案内（説明会・インターン）
3. 授業・課題
4. 奨学金・手続き
5. セキュリティ・ログイン
6. 支払い・請求
7. その他

## 3. 方式（段階制）

### v1 ルールベース
- カテゴリ: キーワード辞書（頻出語）でスコアリングし、最大スコアのカテゴリを採用。同点・低スコアは「その他」
- 期限: 正規表現で日付表現を検出し、「12月20日」「2026/11/13」「来週金曜」等を日付に正規化
- 金額: 「¥12,000」「12,000円」等のパターンを検出
- 行動: 「提出」「申込」「応募」「参加登録」「返信」「支払」等の動詞パターンから行動項目を生成

### v2 機械学習
- TF-IDF + ロジスティック回帰（scikit-learn）でカテゴリ分類器を学習
- v1 のルール結果を初期ラベルとして活用し、学習データを増やす
- 期限・金額・行動の抽出は v1 のルールを継続使用（抽出系はルールが強いため）

### v3 評価と改善
- v1 と v2 の精度を同じテストデータで比較し、改善幅を数値で示す
- 誤分類の傾向（混同しやすいカテゴリ対）を記録し、辞書・学習データへ反映

## 4. 評価設計（成果物の核心）

- テストデータ: 本人が正解ラベルを付けた 50〜100 件。実メールは匿名化した抜粋のみを使い、原本はローカル外に出さない
- 指標: 正解率、カテゴリ別の適合率・再現率・F1、混同行列
- 記録: 評価結果は日付つきで results/ に保存し、改善の履歴が追えるようにする

## 5. 構成（予定）

```
text-classifier/
  README.md          … 概要・使い方・評価結果サマリー（面接での説明資料を兼ねる）
  src/
    rules.py         … キーワード辞書とスコアリング
    extract.py       … 期限・金額・行動の抽出
    classify.py      … 分類の入口（v1/v2 切り替え）
    train.py         … v2 の学習
    evaluate.py      … 精度評価と混同行列の出力
  data/
    samples/         … 合成サンプル（リポジトリに置けるもの）
    private/         … 実データ由来（リポジトリに含めない、.gitignore 対象）
  tests/
    test_rules.py, test_extract.py …
  results/           … 評価結果の履歴
```

## 6. 制約とルール

- 無料範囲のみ（Python、scikit-learn などローカル実行。有料APIは使わない）
- インターンの業務情報・社内情報はデータに使わない
- 実メールの本文はGitHubに上げない。リポジトリにはコード・合成データ・評価結果のみ
- 外部送信・応募などの実行機能は持たせない（分類と抽出だけ）

## 7. 開発ステップ（1ステップ30〜60分目安）

1. リポジトリ作成と雛形（README、構成、.gitignore）
2. v1: 期限・金額の抽出＋テスト
3. v1: カテゴリ分類（キーワード辞書）＋テスト
4. テストデータ作成（正解ラベル付け）と評価スクリプト
5. v2: 機械学習版と比較評価
6. README に評価結果と学びを整理（成果物の仕上げ）

## 8. 将来の接続（ロードマップ第4項への布石）

- メール締切の自動登録（稼働中）の抽出ロジックを、このツールの分類結果に差し替える
- メモ帳ドキュメントの新着メモを入力にして、タスク・締切を自動抽出する
